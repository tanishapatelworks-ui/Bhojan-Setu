# 🍱 BhojanSetu

### Turning Surplus Food into Shared Resources

BhojanSetu is a web-based food rescue platform designed to connect people and organizations with surplus food to communities and individuals who can benefit from it.

The goal is simple: **reduce avoidable food waste by making surplus food easier to discover, donate, and redistribute.**

---

## ✨ Features

* 🍱 **Post Food Donations**
  Donors can share information about available surplus food.

* 🔎 **Discover Donations**
  Users can explore available food and relevant donation information.

* 📍 **Location-Aware Listings**
  Make it easier to identify donations relevant to a particular area.

* 👥 **Community-Focused Platform**
  Designed to connect donors, recipients, and organizations.

* 🔐 **Authentication & Data Management**
  Supabase is used for backend services and data management.

* 📱 **Responsive Design**
  Designed to provide a smooth experience across desktop and mobile devices.

* ⚡ **Modern Web Experience**
  Built with React, TypeScript, and Vite for a fast and maintainable frontend.

## 🏗️ How It Works

```text
Donor
  │
  │  Posts surplus food
  ▼
BhojanSetu
  │
  │  Food listing becomes available
  ▼
Community / Organization
  │
  │  Discovers & coordinates donation
  ▼
Food Redistribution
```

The platform creates a digital connection between **surplus food and potential recipients**, helping make food redistribution more organized and accessible.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/tanishapatelworks-ui/Bhojan-Setu.git
```

### 2. Navigate to the project

```bash
cd Bhojan-Setu
```

### 3. Install dependencies

```bash
npm install
```


### 4. Start the development server

```bash
npm run dev
```

---

## 📦 Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
